# algoritheory_lab2
# Sports Tournament Manager (Спортивная команда)

## Описание
Консольное приложение на Python для управления футбольным турниром. Позволяет создавать команды, добавлять игроков, фиксировать результаты матчей и рассчитывать статистику (очки, голы, пасы). Реализовано в рамках лабораторной работы.

## Инструкции по запуску
1. Клонируйте репозиторий.
2. Установите виртуальное окружение и зависимости:
   ```bash
   python -m venv venv
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
